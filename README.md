# GushWorkFrontEnd
Mangalam HDPE Pipes Website

A modern, fully responsive industrial product showcase website built for Mangalam HDPE Pipes, focused on premium UI/UX, smooth interactions, and conversion-driven design.

The project includes dynamic product presentation, interactive image zoom, technical specification sections, floating product summary bars, responsive layouts, and custom modal-based enquiry systems — all built using HTML, CSS, and Vanilla JavaScript.
